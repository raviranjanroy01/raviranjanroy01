My current interests include:

## Featured Projects

### 🧠 [Emi Core](https://github.com/raviranjanroy01/emi-core)
**Deterministic emotional runtime with LLM-mediated perception and constrained dialogue.**

An experimental architecture that separates probabilistic language-model behavior from deterministic emotional state and response policy. The LLM acts as a semantic sensor and text generator while the core system controls emotional state evolution and behavioral constraints.

**Focus:** Python · Ollama · LLM integration · deterministic state · constrained generation

---

### ⌨️ [AutoAI](https://github.com/raviranjanroy01/auto_ai)
**Local intelligent typing assistant for autocorrection and next-word prediction.**

An experimental typing system combining context-aware correction, n-gram prediction, and user personalization, with a roadmap toward more advanced language models and cross-platform support.

**Focus:** Python · NLP · edit distance · n-gram models · personalization

---

### 📊 [MetricFlow](https://github.com/raviranjanroy01/MetricFlow)
**Analytics platform built around a modern web stack.**

A team project using a React frontend with a FastAPI backend and PostgreSQL/SQLAlchemy data layer.

**Stack:** React · FastAPI · PostgreSQL · SQLAlchemy
